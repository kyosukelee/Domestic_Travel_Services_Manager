# 国内旅行業務取扱管理者試験 問題演習（非公式学習アプリ）

国内旅行業務取扱管理者試験の独学用 Web アプリです。一次資料に基づく独自問題 210 問、本試験形式の模試、苦手論点抽出、フラッシュカード、デイリーチャレンジを収録しています。すべて単一の HTML ファイルで動作し、サーバー不要・データは端末内（localStorage）に保存されます。

---

## 公開・配信の手順（GitHub Pages）

### 必要なファイル

このアプリを PWA（ホーム画面に追加できるアプリ）として正しく動かすには、**次のファイルをすべて同じフォルダに置く**必要があります。

| ファイル | 役割 | リネーム |
|---|---|---|
| `Domestic_Travel_Services_Manager.html` | アプリ本体 | **`index.html` にリネームする** |
| `sw.js` | オフライン動作・インストール用 | リネーム不要 |
| `manifest.webmanifest` | アプリ情報（名前・アイコン・表示方法） | リネーム不要 |
| `icon-192.png` | アプリアイコン（小） | リネーム不要 |
| `icon-512.png` | アプリアイコン（大） | リネーム不要 |

> **重要**：`manifest.webmanifest`・`icon-192.png`・`icon-512.png` の3つは、Chrome / Edge が「アプリをインストール」ボタンを表示するために必要です。これらが無いと、HTML 内の予備機能で簡易的に補われますが、確実にインストール可能にするには 5 ファイルすべてを配置してください。

### 重要な注意点

1. **HTML は必ず `index.html` にリネームしてください。**
   GitHub Pages はフォルダにアクセスされたとき `index.html` を自動的に表示します。これにより `https://ユーザー名.github.io/リポジトリ名/` のシンプルな URL で開けます。

2. **`sw.js` を必ず HTML と同じ階層に置いてください。**
   `sw.js` がないと、ブラウザの「アプリをインストール」ボタンが表示されません（Chrome 等は、オフライン対応の Service Worker が登録されていることをインストール可能の条件とするため）。`sw.js` を置き忘れると、PWA としてインストールできません。

### アップロード後のフォルダ構成（正しい例）

```
リポジトリのフォルダ（または docs/ フォルダ）
├── index.html              ← Domestic_Travel_Services_Manager.html をリネームしたもの
├── sw.js                   ← そのまま
├── manifest.webmanifest    ← そのまま
├── icon-192.png            ← そのまま
└── icon-512.png            ← そのまま
```

## ホーム画面への追加・インストール方法

### iPhone / iPad（Safari）

1. Safari で公開 URL を開く
2. 画面下部の「共有」ボタン（□に↑のアイコン）をタップ
3. メニューを下にスクロールし「**ホーム画面に追加**」をタップ
4. 右上の「追加」をタップ

> iOS の Safari には Android のような「インストール」ボタンはありません。「ホーム画面に追加」が iOS でのインストール操作です。これはアプリの作りに関係なく Safari の仕様です。

### Android（Chrome）

1. Chrome で公開 URL を開く
2. アドレスバー右の「︙」（メニュー）をタップ
3. 「**アプリをインストール**」または「ホーム画面に追加」をタップ

> 「アプリをインストール」が表示されない場合は、`sw.js` が同じフォルダに置かれているか確認してください。

### PC（Chrome / Edge）

1. 公開 URL を開く
2. アドレスバーの右端に表示される「インストール」アイコン（⊕ や画面に↓のようなアイコン）をクリック
3. 「インストール」をクリック

> アイコンが出ない場合は、アドレスバーの「︙」メニュー →「保存して共有」→「ページをアプリとしてインストール」等から行えます。

## 「インストール」ボタンが出ないときのチェックリスト

ブラウザがアプリのインストールを提案するには、いくつかの条件をすべて満たす必要があります。

- [ ] **HTTPS で配信されているか**（GitHub Pages は自動で HTTPS。`http://` や `file://` では不可）
- [ ] **`manifest.webmanifest`・`icon-192.png`・`icon-512.png` が HTML と同じフォルダにあるか**（最も多い見落とし）
- [ ] **`sw.js` が HTML と同じフォルダにあるか**
- [ ] **HTML を `index.html` にリネームしたか**
- [ ] **ハード再読み込みしたか**（Ctrl + Shift + R。Service Worker や manifest はキャッシュされやすいため、更新後は強制再読み込みが必要）
- [ ] **iPhone の場合**：Safari を使っているか（Chrome アプリ版では「ホーム画面に追加」ができません。iOS では Safari を使用）
- [ ] すでにインストール済みでないか（インストール済みだと再度ボタンは出ません）

### 確認方法（PC Chrome の場合）

1. 公開ページで F12 キーを押して開発者ツールを開く
2. 「Application（アプリケーション）」タブを開く
3. 左メニューの「Manifest」をクリック → アイコンや名前が表示されていれば manifest は正常
4. 左メニューの「Service Workers」をクリック → 登録されていれば SW は正常

両方とも正常なら、インストール可能な状態です。

## 機能一覧

- **演習モード**：科目別・論点別に絞り込んで 4 択演習、即時採点・解説・出典表示
- **模試モード**：本試験形式（3 科目各 20 問・60 分制限・科目別 60 点で合否判定）
- **苦手論点抽出**：正答率の低い論点を自動で Top 5 表示
- **論点別習熟度マップ**：全論点の習熟度を色分け表示、クリックでその論点だけ演習
- **復習**：ブックマークした問題・誤答した問題をまとめて確認・再演習
- **フラッシュカード**：表（問題）→裏（正解＋解説）の暗記学習
- **デイリーチャレンジ**：毎日 10 問・連続日数（ストリーク）記録
- **学習履歴・進捗ダッシュボード**
- **データのエクスポート / インポート**（端末間の移行用）

- 単一 HTML ファイル（HTML + CSS + JavaScript、フレームワーク不使用）
